- 方針で組み立てたものに加えていくつか工夫が必要
  - 工夫で頭のメモリを取られてしまうのがまだ馴染んでいない証拠か。。
  - 通るコードは書いたけど、どっちかというと inorder, preorder を正しく理解しているのか？それぞれから元の木を頭の中で組み上げられるか？の方が重要だと思う(ちなみに、inorder のみから元の構造を複合するのは無理、なぜならどこがルートかわからないから。preorder のみでも無理、[1,2] から 1 left to 2, 1 right to 2 の両方が作れてしまい、left or right が一意に定まらないから)
  - 例えば、他のトラバーサルの組み合わせでは複合できるのか？とか？何と何があれば複合できるんだっけ？を理解しておけばそこまで怖くはないはず
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    int[] preorder;
    Map<Integer, Integer> inorderWithIndex = new HashMap<>();
    
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        this.preorder = preorder;
        for (int i = 0; i < inorder.length; i++) {
            inorderWithIndex.put(inorder[i], i);
        }
        return buildTreeHelper(0, 0, inorder.length - 1);
    }

    private TreeNode buildTreeHelper(int preIndex, int inStart, int inEnd) {
        if (inStart > inEnd) {
            return null;
        }
        int rootVal = preorder[preIndex];
        TreeNode root = new TreeNode(rootVal);
        int rootIndexInInorder = inorderWithIndex.get(rootVal);

        root.left =  buildTreeHelper(preIndex + 1, inStart, rootIndexInInorder - 1);
        root.right = buildTreeHelper(preIndex + (rootIndexInInorder - inStart) + 1, rootIndexInInorder + 1, inEnd);

        return root;
    }
}
```
